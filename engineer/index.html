Things I built that runЧто я собрала и что работает

  1. 01

    Design system in codeДизайн-система в коде

    Components from a fintech design system rebuilt in React and TypeScript with Claude Code. Tokens live in one JSON and generate CSS, props mirror the Figma component properties. Every story runs axe: the tests caught a contrast bug and a loading button with no accessible name – neither was visible in Figma

    Компоненты финтех-дизайн-системы, пересобранные на React и TypeScript с Claude Code. Токены лежат в одном JSON и генерируют CSS, пропсы повторяют свойства компонентов в Figma. Каждая story проходит axe: тесты поймали ошибку контраста и кнопку загрузки без доступного имени – в Figma не было видно ни того, ни другого

  2. 02

    AI agents for UX copy and localisationAI-агенты для текстов и локализации

    Built with the design lead on Claude. The agents write to our editorial rules, check and translate every string into 13 languages and put them straight into the iOS and Android code as a branch ready to merge. The team dropped Phrase after that

    Собрали вместе с лидом дизайна на Claude. Агенты пишут по нашей редполитике, проверяют и переводят каждую строку на 13 языков и кладут их сразу в код iOS и Android – веткой, готовой к мерджу. После этого команда отказалась от Phrase

  3. 03

    A clickable prototype in plain JavaScriptКликабельный прототип на чистом JavaScript

    The whole Cards flow runs in the browser: issue, top up, card details, freeze. Screens slide, sheets rise and states cross-fade like in the app, and a scripted demo plays it for anyone who won’t click

    Весь сценарий карт работает в браузере: выпуск, пополнение, данные карты, заморозка. Экраны сдвигаются, шторки поднимаются, состояния сменяются как в приложении, а для тех, кто не хочет кликать, есть демо, которое проигрывается само

  4. 04

    This portfolioЭто портфолио

    Hand-built with Claude Code: static HTML, CSS and JS on a 4 px grid, two languages in one page, self-hosted fonts. A Python build strips dev-only styles, reserves every image’s box so the page doesn’t jump, fixes Russian line breaks and cache-busts assets before pushing to GitHub Pages

    Собрано руками с Claude Code: статичные HTML, CSS и JS на сетке 4 px, два языка в одной странице, свои шрифты. Сборка на Python вырезает dev-стили, резервирует место под картинки, чтобы страница не прыгала, чинит переносы предлогов и сбрасывает кэш ассетов перед публикацией на GitHub Pages
