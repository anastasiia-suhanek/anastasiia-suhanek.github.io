Profee · 2025 – nowсейчасiOS · Android · Web

A new design system for a money transfer appНовая дизайн-система приложения для денежных переводов

In progress since summer 2025. With the design lead and front-end developers I build components and tokens in Figma Variables, and earlier worked with the UX writers on the copy rules that live inside components. The verification entry point I designed is one of its components, shared by app and web

Строится с лета 2025. Вместе с лидом дизайна и фронтенд-разработчиками завожу компоненты и токены в Figma Variables, а раньше мы с UX-редакторами задавали правила текстов внутри компонентов. Точка входа в верификацию, которую я придумала, — один из её компонентов, общий для приложения и веба

10verification scenarios, one componentсценариев верификации, один компонент

One component instead of ten screensОдин компонент вместо десяти экранов

KYC had ten scenarios, each asking for something different. I designed one entry point in three forms – a card, a bottom sheet and a status banner – and built it into the system with the design lead. Each scenario switches on its own illustration, text and buttons. Verification questions to support halved: −54%

В KYC было десять сценариев, и в каждом от человека нужно что-то своё. Я придумала одну точку входа в трёх формах — карточка, шторка и баннер статуса — и вместе с лидом завела её в систему. Каждый сценарий включает свою иллюстрацию, текст и кнопки. Вопросов про верификацию в поддержку стало вдвое меньше: −54%

The same components, checked in codeТе же компоненты с проверкой в коде

An anonymised sample of the system rebuilt in React and Storybook. Tokens live in one JSON, props mirror the Figma properties one to one. The tests caught secondary button text at 3.98:1 – it looked fine in Figma. A darker token fixed it: 5.3:1

Обезличенная часть системы, пересобранная на React и Storybook. Токены лежат в одном JSON, пропсы один в один повторяют свойства в Figma. Тесты поймали текст вторичной кнопки с контрастом 3,98:1 — в Figma он выглядел нормально. Исправила более тёмным токеном: 5,3:1

Copy as part of the systemТексты как часть системы

With the design lead we built Claude agents that write to our editorial rules and translate every string into 13 languages. Localising a feature went from a day to about two hours, and strings go straight into the iOS and Android code

С лидом дизайна собрали агентов на Claude, которые пишут по нашей редполитике и переводят каждую строку на 13 языков. Локализация фичи сократилась с дня до примерно двух часов, а строки уходят сразу в код iOS и Android

02 — PrinciplesПринципы

How I build a systemКак я строю систему

  • primitives → semantic

    Components never see raw valuesКомпоненты не видят сырых значений

    Only semantic tokens. A partner brand or dark mode is a new mode, not a redraw

    Только семантические токены. Бренд партнёра или тёмная тема — новый режим, а не перерисовка

  • property = prop

    Figma speaks the code’s languageFigma говорит на языке кода

    A toggle in Figma is a prop in React with the same name, so handoff has nothing to translate

    Переключатель в Figma — это проп в React с тем же именем, поэтому при передаче нечего переводить

  • 1 × n

    Fewer components, more casesМеньше компонентов, больше сценариев

    Ten verification scenarios run on one bottom sheet. New scenario, no new component

    Десять сценариев верификации работают на одной шторке. Новый сценарий — без нового компонента

  • axe

    Test what the eye missesПроверять то, что пропускает глаз

    Contrast and accessible names are checked on every story, not in a review once a quarter

    Контраст и доступные имена проверяются на каждой story, а не на ревью раз в квартал

  • 4 px

    One grid for everythingОдна сетка для всего

    Spacing, type and component sizes are multiples of 4. This site follows it too

    Отступы, шрифты и размеры компонентов кратны 4. Этот сайт тоже

  • 13 langs

    Copy is part of the componentТекст — часть компонента

    Rules for length, tone and states live with the component, and the longest language decides the layout

    Правила длины, тона и состояний живут вместе с компонентом, а вёрстку задаёт самый длинный язык
